`battery-soc-soh-aging-estimation` is a reproducible Battery Management System (BMS) project for lithium-ion battery modeling, State of Charge (SOC) estimation, State of Health (SOH) tracking, and aging-aware observer adaptation.

The current **V1.1.1** portfolio release implements:

- a discrete second-order Thevenin equivalent circuit model (2-RC ECM);
- a nonlinear, monotonic synthetic OCV-SOC relationship and analytical derivative;
- a deterministic dynamic current-profile and noisy sensor-data generator;
- Coulomb Counting, Extended Kalman Filter (EKF), and Unscented Kalman Filter (UKF);
- capacity-fade and resistance-growth SOH indicators;
- bounded aging-aware capacity and resistance adaptation;
- NumPy-only pulse-relaxation parameter identification;
- nominal, aged fixed-parameter, and aged adaptive benchmark scenarios;
- JSON metrics, CSV datasets, Markdown reports, and PNG figures;
- automated unit and integration-level algorithm tests;
- measured-data parameter identification on CALCE DST and independent validation on CALCE FUDS;
- measured capacity-fade and resistance-growth validation on eight Oxford aging cells;
- full-life CALCE CX2-3 capacity and strict 5-second pulse-resistance extraction;
- measured-aging-informed fresh/aged/estimated-aging-aware observer comparison;
- initial-SOC, measurement-noise, and parameter-uncertainty robustness matrices.

> Measured-data results use public CALCE and Oxford laboratory data; they do not imply that the repository author performed the cell experiments. The aging-aware dynamic comparison is explicitly semi-empirical: its health factors are measured, while its dynamic SOC/voltage trajectory is generated by the 2-RC model.

## Motivation

SOC and SOH cannot be measured directly by normal onboard sensors. They must be inferred from current, terminal voltage, temperature, and a battery model. Practical estimators must tolerate incorrect initial SOC, measurement noise, parameter uncertainty, capacity fade, and resistance growth.

This project connects those problems in one transparent workflow:

```text
Dynamic current profile + battery condition
                  |
                  v
          2-RC ECM simulation
                  |
        noisy current and voltage
                  |
      +-----------+-----------+
      |           |           |
 Coulomb Count   EKF         UKF
      |           |           |
      +-----------+-----------+
                  |
       SOC metrics and plots
                  |
       SOH-aware parameter map
```

## 2-RC Thevenin Model

Using discharge-positive current, the model is:

```math
\frac{d z}{dt}=-\frac{\eta I}{3600Q},
\qquad
\frac{dV_i}{dt}=-\frac{V_i}{R_iC_i}+\frac{I}{C_i},
\quad i\in\{1,2\}
```

```math
V_t=V_{OC}(z)-IR_0-V_1-V_2.
```

The RC states use their analytical discrete-time solution. SOC is bounded to $[0,1]$. The EKF uses the analytical OCV derivative, while the UKF propagates sigma points through the nonlinear model without explicit measurement linearization.

## SOC Estimators

### Coulomb Counting

Coulomb Counting is the transparent baseline. It exposes drift caused by initial-SOC error, current bias, and capacity mismatch.

### Extended Kalman Filter

The EKF state is $[SOC,V_1,V_2]^T$. The implementation includes nonlinear prediction, voltage correction, covariance propagation, Joseph-form covariance update, state bounding, and covariance symmetrization.

### Unscented Kalman Filter

The UKF uses scaled sigma points with configurable $\alpha$, $\beta$, and $\kappa$. The implementation includes Cholesky jitter, an eigenvalue fallback, nonlinear voltage prediction, covariance stabilization, and physical SOC bounds.

## SOH and Aging-Aware Adaptation

The project reports two independent health indicators:

```math
SOH_Q=\frac{Q_{usable}}{Q_{rated}}\times100\%,
\qquad
SOH_R=\frac{R_{reference}}{R_{estimated}}\times100\%.
```

The observer can update usable capacity and ECM resistance from slow health estimates. Capacity and resistance factors are bounded before being applied to the fast SOC observer.

The original controlled benchmark can inject a known synthetic health condition. The measured-aging-informed benchmark instead estimates capacity and resistance factors causally from CALCE CX2-3 diagnostic cycles and feeds those estimates back into the SOC observer.

## Parameter Identification

`scripts/identify_parameters.py` demonstrates a reproducible pulse-relaxation workflow:

- $R_0$ from the instantaneous current-step voltage drop;
- two relaxation time constants from a constrained logarithmic grid;
- branch amplitudes from linear least squares;
- held values and output metrics written to JSON.

The current identification input is synthetic and deliberately noisy. The identification routine itself uses NumPy only; measured-data processing elsewhere in the project uses the dependencies declared in `pyproject.toml`, including SciPy where required.

The measured validation uses official open experimental data from the [CALCE Battery Research Data repository](https://calce.umd.edu/data):

- Samsung INR18650-20R, NMC/graphite, rated 2.0 Ah;

- OCV-SOC curve: incremental-current OCV test;
- ECM identification: DST at nominal 80% SOC;
- independent validation: FUDS at nominal 80% SOC;
- estimator initialization: 10 percentage points below the capacity-derived SOC reference.

The OCV test and dynamic profiles come from different cells of the same model. The fitted 9.8 mV OCV bias and the remaining cross-cell uncertainty are reported rather than hidden.

## Oxford Measured SOH and Aging Validation

SOH and resistance-growth validation uses [Oxford Battery Degradation Dataset 1](https://ora.ox.ac.uk/objects/uuid:03ba4b01-cfed-46d3-9b1a-7d4a7bdf6fac), DOI `10.5287/bodleian:KO2kdmYGg`:

- eight Kokam SLPB533459H4 lithium-ion pouch cells;
- rated capacity: 740 mAh;
- environmental temperature: 40 degrees Celsius;
- 1C and pseudo-OCV characterization every 100 cycles;
- up to approximately 8,200 equivalent full cycles.

Capacity retention is calculated relative to each cell's first measured 1C discharge capacity. Rated-capacity SOH uses the datasheet denominator, `capacity_mAh / 740 mAh * 100`. Effective resistance is estimated from the voltage difference between aligned 1C and pseudo-OCV discharge curves over 20-80% depth of discharge.

| Measured aging result | Value |
|---|---:|
| Mean initial capacity | 733.44 mAh |
| Initial capacity standard deviation | 3.51 mAh |
| Mean final capacity retention | 75.50% of initial measured capacity |
| Final capacity retention range | 62.03-79.97% |
| Mean final rated-capacity SOH | 74.82% of 740 mAh |
| Final rated-capacity SOH range | 61.64-78.76% |
| Mean initial effective resistance | 0.04635 ohm |
| Mean final resistance factor | 1.704x |

A simple aging-trend benchmark trains on the first 60% of each cell's characterization points and evaluates on the remaining 40%:

| Capacity-retention trend model | Holdout RMSE [%pt] | Holdout MAE [%pt] |
|---|---:|---:|
| Linear | 2.847 | 2.266 |
| Quadratic | 1.908 | 0.896 |

![Oxford measured SOH validation](results/figures/oxford_soh_validation.png)

Sudden capacity and resistance changes in individual cells are retained as measured. They are not removed merely to improve the benchmark. The trend models are transparent offline baselines, not production remaining-useful-life predictors.

## CALCE CX2-3 Full-Life Pulse Aging and Observer Feedback

The full-life CX2-3 archive supplies 61 valid dated exports and 1,185 sampled diagnostic cycles from September 2010 to February 2013. For each complete cycle:

- usable capacity is obtained from the full-discharge capacity increment;
- 5-second pulse resistance is calculated from the voltage change between the end of the 10-second rest and the first 5-second sample of the 0.5C pulse, divided by the measured current step;
- file-level values are medians of valid cycles, reducing sensitivity to isolated bad cycles;
- a causal three-checkpoint median supplies the health estimate used by the observer.

The complete measured curve retains the cell's abrupt end-of-life collapse. Observer evaluation uses the operational checkpoint closest to 70% capacity SOH rather than extrapolating through the collapse.

![CALCE CX2-3 measured aging](results/figures/cx2_pulse_aging.png)

| CX2-3 observer checkpoint | Diagnostic value | Causal estimate |
|---|---:|---:|
| Capacity factor | 0.6946 | 0.7055 |
| 5 s pulse-resistance factor | 1.3194x | 1.3003x |

The observer comparison uses one independent dynamic profile generated by the 2-RC ECM at the measured aged condition. Therefore this is a **semi-empirical adaptation benchmark**, not a claim of measured dynamic-voltage validation.

| Parameter case | EKF RMSE [%pt] | UKF RMSE [%pt] | EKF post-300 s RMSE | UKF post-300 s RMSE |
|---|---:|---:|---:|---:|
| Fresh fixed | 3.178 | 2.876 | 2.848 | 2.680 |
| Aged fixed (oracle) | 1.491 | 0.403 | 0.836 | 0.273 |
| Estimated aging-aware | 1.548 | 0.520 | 0.906 | 0.399 |

![Measured-aging-informed observer comparison](results/figures/aging_aware_comparison.png)

## Quick Start

Clone the repository:

```bash
git clone https://github.com/Jerry-124/battery-soc-soh-aging-estimation.git
cd battery-soc-soh-aging-estimation
```

Create an environment and install the project with development tooling:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

If dependencies are already available but network access is restricted, use `python -m pip install -e . --no-deps --no-build-isolation`.

Linux or macOS:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

Run verification:

```bash
python -m pytest -q
ruff check .
```

Run parameter identification and all benchmarks:

```bash
python scripts/identify_parameters.py
python scripts/run_experiment.py --config configs/experiments/soc_benchmark.yaml
python scripts/run_experiment.py --config configs/experiments/aged_fixed_benchmark.yaml
python scripts/run_experiment.py --config configs/experiments/aging_aware_benchmark.yaml
python scripts/generate_report.py
```

Download the official CALCE files and run independent measured-data validation:

```bash
python scripts/download_calce_data.py
python scripts/run_calce_validation.py
```

Downloaders require validated HTTPS endpoints, restrict known datasets to allow-listed hosts, revalidate the final redirect destination, and verify the expected SHA-256 before data are used.

Download the Oxford aging dataset and run measured SOH validation:

```bash
python scripts/download_oxford_data.py
python scripts/run_oxford_soh_validation.py
```

The Oxford MATLAB file is approximately 254 MiB and requires SciPy. It is SHA-256 verified and excluded from Git.

Download and verify the official CX2-3 archive, then run the full-life pulse-aging, observer-feedback, and robustness stages:

```bash
python scripts/download_calce_cx2_data.py
python scripts/run_cx2_pulse_aging.py
python scripts/run_aging_aware_comparison.py
python scripts/run_robustness_matrix.py
```

After the first extraction, `python scripts/run_cx2_pulse_aging.py --reuse-records` rebuilds figures and metrics from the processed cycle table without rereading the large workbooks.

Generated artifacts are saved under `data/processed/` and `results/`; selected reproducibility artifacts are intentionally versioned while bulky raw/intermediate data remain ignored.

## Scope

This repository is an educational and portfolio-quality algorithm-development project. It is not a production-certified BMS, safety component, or substitute for cell-level validation.

Initial scope includes cell-level lumped electrical modeling, SOC/SOH estimation, aging-aware observer behavior, controlled robustness evaluation, and reproducible reporting.

Pack balancing, electro-thermal gradients, fault diagnosis, embedded deployment, hardware-in-the-loop testing, and functional-safety certification are outside the current scope.

## Status

**V1.1.1 portfolio patch: working synthetic, measured-data, and semi-empirical aging-aware validation pipeline with corrected scientific semantics.** The project identifies the ECM on CALCE DST data, validates SOC estimation on independent CALCE FUDS data, extracts capacity fade and pulse-resistance growth from CALCE CX2-3 and Oxford aging data, feeds measured health estimates back into EKF/UKF observers, and runs three robustness matrices. V1.1.1 separates true full-state open-loop voltage validation from reference-SOC-conditioned diagnostics, aligns the EKF Jacobian with the piecewise-linear CALCE OCV curve, and distinguishes Oxford first-characterization retention from rated-capacity SOH. Remaining work focuses on multiple temperatures, cross-cell SOC robustness, and joint online SOC-SOH estimation during ordinary dynamic operation.
