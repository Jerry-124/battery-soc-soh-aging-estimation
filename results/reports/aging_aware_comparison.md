# Aging-Aware SOC Observer Comparison

## Scope

This is a semi-empirical benchmark: capacity and resistance health factors are measured from CALCE CX2-3, while the dynamic SOC/voltage trajectory is generated by the 2-RC ECM.

## Key Results

| Parameter Case | Observer | RMSE | Post-300 s RMSE |
|---|---|---:|---:|
| Fresh fixed | EKF | 3.178 %pt | 2.848 %pt |
| Fresh fixed | UKF | 2.876 %pt | 2.680 %pt |
| Aged fixed (oracle) | EKF | 1.491 %pt | 0.836 %pt |
| Aged fixed (oracle) | UKF | 0.403 %pt | 0.273 %pt |
| Estimated aging-aware | EKF | 1.548 %pt | 0.906 %pt |
| Estimated aging-aware | UKF | 0.520 %pt | 0.399 %pt |

## Interpretation

The aging-aware observer uses causal health estimates rather than oracle aged parameters. The oracle case is retained only as a reference bound. Because the dynamic trajectory is simulated, these numbers should not be interpreted as measured dynamic-voltage validation.
